## Install

Needs Calagopus Panel 1.2.0 or newer.

1. Download `dev_s4way_nebula.c7s.zip` from the [latest release](../../releases/latest).
2. In the panel: Admin, then Extensions, then install the file.
3. Restart the panel.

## Editor

Admin, then Theme Editor. Colours, fonts, corners, button styles, background, per egg artwork,
getting started links and the home page layout, with a live preview. Saving applies it for everyone.
